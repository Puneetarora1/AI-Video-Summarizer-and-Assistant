
# 🎥 AI Video Summarizer & Assistant

## 📌 Project Overview

An AI-powered application that summarizes YouTube videos and local video files, extracts key insights, and enables users to ask questions about video content.
The application transcribes video audio using OpenAI Whisper, generates structured summaries using Google's Gemini model, and provides a RAG-based chatbot for context-aware question answering.

## 🎯 Objectives

- Convert video audio into text.
- Extract summary, actionable items, key decisions, and open questions.
- Enable conversational question answering over video transcripts.
- Build REST APIs using FastAPI and an interactive user interface.

## ⚙️ Tech Stack

- **Language:** Python
- **Audio Processing:** yt-dlp, Pydub (AudioSegment)
- **Speech Recognition:** OpenAI Whisper
- **LLM Integration:** LangChain, ChatGoogleGenerativeAI (Gemini)
- **RAG:** Vector Store, Semantic Retrieval
- **Backend:** FastAPI
- **Version Control:** Git, GitHub
